# Configs

Тут зберігаються версіоновані конфігурації експериментів. Кожна headline-таблиця має посилатися на конкретний config і git commit.

Мінімальні секції: dataset, input, slam, geometry_model, alignment, fusion, evaluation, runtime. Секрети, абсолютні user-specific paths і токени в config заборонені.

experiment.example.yaml — контракт-приклад; він ще не підключений до executable code.
